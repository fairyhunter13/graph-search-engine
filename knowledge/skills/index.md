# Skill

* [Run a pinned pytest measurement and return a receipt](run-pytest-measure.md) - The run procedure
  behind every Attested Computation in this bundle. It runs one anchored test against the pinned
  corpus, reads the numbers out of the run, and returns the receipt fields the attester inspects.
* [Run the two-engine caller-question set and return a receipt](run-two-engine-measure.md) - The run
  procedure behind the routing-rule measurement. It runs one anchored test over this repo's own tree
  with both engines live, reads the scores out of the run, and returns the receipt fields the
  attester inspects.
